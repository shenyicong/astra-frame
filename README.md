## 📌 这是什么

一座被战争迷雾覆盖的遗迹设施。你驾驶一台战甲进入，视野只有身周十几米，
必须边推进边点亮地图，清剿残存的巡逻兵与无人机。

**所有内容都是程序化生成的** —— 没有模型文件、没有贴图文件、没有音频文件。
角色、场景、材质、音效用代码现场合成，仓库里只有一个 Three.js 库。

> 本项目是原创的独立作品，风格上致敬科幻机甲题材，不包含任何商业游戏的素材、模型或商标内容。

## ⚡ 特性

**战争迷雾**
- 地图被标量迷雾覆盖，只有视野范围内可见
- **走过的地方持续白光高亮**，不会随时间变黑，一眼看清已经开过的区域
- 顶棚灯带读取同一张迷雾贴图：未探索区域直接 `discard`，推进时才逐段点亮
- 迷雾中的敌人不渲染、也不可能被击中
- 小地图由迷雾数据实时生成，探索进度百分比 + 进度条同步显示

**关卡推进**
- 通关条件：**本区探索率达到 72%** 且 **场上敌人清空**，两者都满足才进入下一区
- 共 3 关，逐关递增敌人数量（18 → 24 → 30）、血量倍率（1.0 / 1.25 / 1.55）与移动速度
- 每关重置迷雾与地图进度，护盾生命弹药全部补满
- 清完最后一关结束游戏，HUD 顶部实时显示 `区域 n / 3`

**战斗手感**
- 即时命中（hitscan）+ 曳光弹 + 命中火花 + 枪口闪光
- 移动会放大弹道散布，静止射击更准
- 后坐力抬枪、护盾延迟回复、换弹动画
- 两种敌人：地面巡逻兵（保持中距离侧移射击）与悬浮无人机（浮空绕飞）

**程序化美术**
- 金属地板/装甲墙面：由分形噪声生成漫反射贴图，再由高度图推导法线贴图
- 过肩第三人称相机：带墙体避让与高度夹取，贴墙自动拉近，永远看得见自己的战甲
- 跳跃可越过货箱：脚底高于箱顶时箱子不再阻挡，落下时还能稳稳站在箱顶
- 战甲机体：20 余个基础几何体拼装，含自发光能量线路，走路/后坐/呼吸全部程序化动画
- 指数雾 + ACES 色调映射 + 单一投影光源，营造压抑的探索氛围

## 🚀 运行

**直接玩线上版（推荐）**：打开 **https://shenyicong.github.io/astra-frame/** ，点击画面开始
（会请求鼠标锁定，这样视角才跟手）。

> 无需安装任何环境，手机/平板/公司电脑都能直接打开。

**想在本地改代码**：项目用的是 ES Module，直接双击 `index.html` 会被浏览器的同源策略拦住，
需要起一个本地服务：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

启动后访问自己的本地地址（如 `http://localhost:8000`）即可调试。

## 🏎️ 为了「无卡顿」做了什么

这是项目的重点，逐条都可以在代码里对上：

| 手段 | 说明 |
|---|---|
| **实例化渲染** | 墙体、货箱、灯带各用 `InstancedMesh`，数百个物件压缩到个位数 draw call |
| **固定步长逻辑** | 逻辑锁定 60Hz 并与渲染解耦，掉帧不会让物理和 AI 行为变形；单帧最多补 3 步，防止追帧雪崩 |
| **动态分辨率** | 实时统计帧率，低于阈值自动降采样（0.72–1.5 倍），回升后再逐步恢复 |
| **对象池** | 曳光弹、火花、敌人弹丸全部预分配，战斗中零 `new`、零 GC 抖动 |
| **单光源投影** | 只有玩家手电投射阴影，1024 阴影贴图 + 有限阴影相机；其余光源不投影 |
| **迷雾节流** | 迷雾贴图只在跨格且冷却结束时上传，不是每帧刷新 |
| **小地图节流** | 用 80×80 的 `ImageData` 一次写入再放大，10Hz 刷新 |
| **DOM 写入节流** | HUD 数值只在变化时写，避免每帧触发重排 |
| **避免每帧分配** | 复用的 `Vector3` 临时对象，热路径不产生垃圾 |

在集成显卡上，1080p 可以稳定跑到 60 FPS。
